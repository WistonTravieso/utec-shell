\# Shell, introducción - Basics

 Proyecto de introducción a la Shell de Linux

 ## Descripción de los script

0-current\_working\_directory: Imprime el nombre de la ruta absoluta del directorio de trabajo actual.
1-listit: Muestra el contenido del directorio de trabajo actual. 
2-bring\_me\_home: Cambia el directorio de trabajo actual al directorio personal del usuario. 
3-listfiles: Muestra el contenido del directorio de trabajo actual en formato largo. 
4-listmorehiddenfiles: Muestra el contenido del directorio de trabajo actual en formato largo, incluyendo archivos ocultos. 
5-listfilesdigitonly: Muestra el contenido del directorio de trabajo actual en formato largo, con IDs de usuario y grupo numéricos, incluyendo archivos oculto.
6-firstdirectory: Crea un directorio llamado my\_first\_directory en la carpeta /tmp/. 
7-movethatfile: Mueve el archivo betty de /tmp/ a /tmp/my\_first\_directory. 
8-firstdelete: Elimina el archivo betty ubicado en /tmp/my\_first\_directory/. 
9-firstdirdeletion: Elimina el directorio my\_first\_directory ubicado en /tmp/. 
10-back: Cambia el directorio de trabajo actual al directorio anterior.
